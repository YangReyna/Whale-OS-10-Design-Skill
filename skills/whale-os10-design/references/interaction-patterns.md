## 全局焦点规则

`20470:73363` 的非锁定焦点示意区分 **Slot（屏幕槽位）** 与 **Source（内容项目）**：在可见区域内左右移动会改变槽位和内容；到可见区域边缘继续移动时可保持槽位、滚动内容。示例首尾还有边界，不可仅凭滚动示意推断循环列表。按目标行核对“下一项目”“下一槽位”“数据末项”，三者不同。

`20470:74018` 明文区分：

- 一般情况：按就近原则映射到对应元素，不应用焦点记忆。
- 指定的一对多情况：按图示对应关系；第一次进入对应行落在首项；应用焦点记忆。明确列举 Home Banner ↔ Your Top Choice、认证 Apps ↔ 对应推荐内容，以及 Discovery / Apps Banner ↔ 下一内容行。

这不是“全站永远记忆”或“全站永远回首项”。返回恢复、跨行映射和列表滚动分别按当前场景处理。

## Settings：项目已有模式

来源 `20470:74560`。它有清晰的项目交互说明；同 Page 另有 `53954:79974` 补充画面与长篇 Description，其中含通用建议和占位内容，未核实其定稿状态，不能单独作为统一规范。

- 非全屏设置，一屏呈现两个层级，左为高层级，右为下一级；未覆盖区域继续显示原内容。
- 一级左侧菜单移动焦点时，右侧内容实时变化；OK 进入下一级，默认落在首项。
- 深入层级时，下一级左滑到上一级位置，原高层级左滑淡出，新的低层级从右侧出现。非一级时，操作焦点位于右侧层级。
- BACK 回到上一层级的原条目；来源有“从哪里来，回哪里去”的明确表述。
- 列表样例一屏最多六项：向下到第 5 槽后继续滚动时固定焦点、内容上移；末项进入第 6 槽后允许焦点移至末槽。向上到第 2 槽时采用相应固定焦点滚动。此为该 Settings 列表规则，不扩展到所有内容行。

| 控件/模式 | 已有说明中的按键行为 |
| --- | --- |
| 开关 | 获焦时 OK 切换；LEFT 回上级，RIGHT 无交互 |
| 单选 | OK 选中；LEFT 回上级，RIGHT 无交互 |
| 多选 | OK 选中/取消；LEFT 回上级，RIGHT 无交互 |
| 下一级入口 | OK 或 RIGHT 进入，LEFT 回上级 |
| 参数切换 | OK 激活编辑并显示左右箭头；LEFT/RIGHT 换值，选定值自动生效；首次 BACK 退出编辑，再次 BACK 返回上级 |
| 连续数值 | OK 激活后，RIGHT 增大、LEFT 减小，参数动态反馈；不要把编辑中的 LEFT 当作退出 |
| 数字输入样例 | 默认第一位，UP/DOWN 改数字，OK 依次到下一位，也可 LEFT/RIGHT 选位；移至 OK 按钮再提交 |

新任务若更改此模式，必须同时处理退出编辑、提交/取消语义和返回焦点；不可因其与移动端习惯不同而默默改成另一套规则。

## Home：联动与时间阶段

来源 `23640:113307`、`23640:113355` 和 Home 状态画面。

- 已读说明中，Apps Row 前六项为 Recent Source、Netflix、YouTube、Prime Video、Disney+、Whale TV+。
- 认证 Apps 获焦会联动其推荐内容；其他 Apps 对应 Your Top Choice。Netflix 有未登录/已登录的 DET 分支。
- 所读默认 Home 说明落焦 Netflix；这是该版本/状态的依据，不能扩展到任何入口、地区和设备。
- Netflix → YouTube 的所读说明明确写出 **400ms 延迟后换推荐**。编辑提示在相关可编辑 App 获焦时出现，所读说明写 5 秒消失。两种计时适用对象不同，不能统一成全局延时。
- 文件还包含 Home 无网、首次无网、加载中、Banner placeholder、无资源、半焦点、Apps Edit 和滚动状态。设计对应功能时回到这些状态核对恢复路径。

设计新联动要分清短暂经过、稳定停留、内容载入、内容可操作几个阶段，避免焦点已移动而旧异步结果覆盖新内容；这属于设计验证建议，具体阈值不由本技能预设。

## OOBE：可追溯的流程片段

页面目录覆盖 Boot、语言、地区、遥控器配对、网络、TOU、登录/注册、Setting Up、语音助手和过渡；目录顺序不等于所有机型的最终流程。

已读的具体闭环：

1. Boot 后进入 Language Selection，默认 English；UP/DOWN 换语言，右侧问候语随语言变化，OK 确认进入 Region Selection。该状态 LEFT/RIGHT/BACK 为 Null。
2. 遥控器配对后进入 Network Connection，默认 Wireless，另有 Wired 和 Skip；无线项 OK 打开无线设置，BACK 回配对的 Next。
3. 从 Wired 按 DOWN 到 Skip；Skip 按 OK 跳过网络并到 TOU，默认 Select All。不要把 Skip 推断成完成全部 OOBE 或同意协议。

来源：`4109:42251`、`4238:66890`、`4328:6613`。样例显示第 1/8、4/8 步；后续 Child Code、AirPlay 等扩展也存在，不能将“八步”固定为所有 SKU 的要求。

## Search 与 Apps：已有异常/返回例子

Search `23269:50132`：导航 Search 按 OK 进入搜索，焦点在输入框；输入状态打开键盘；BACK 先关闭键盘并回输入框。页面返回 Home 时展开导航并落焦 Search。DOWN 从输入框到 Popular Search 首项，再到语音提示区域。所读提示有 5 秒轮换与另一个 3 秒操作提示，必须分别对应各自状态。

Apps `23269:71340`：更新中断网则暂停并显示网络提示，恢复网络继续；安装失败包含 Later / Retry 分支；存储不足有清理空间提示。恢复进度、重新安装、取消更新是不同操作，不能统一成“重试”。新的异步任务应明确返回的页面、焦点和任务是否继续。

## OS 10.4 的明确版本差异

- `34750:33627` 对比标注：旧版 Discovery Tab 按 OK 无交互；10.4 按 OK 焦点到第一张卡片。不得复用旧版 Null 覆盖这一变化。
- `41327:73239` 的详情页说明：从卡片 OK 进入详情，默认首个播放源；先载入海报，海报显示 3 秒后有预告才播放预告。播放源 OK 可能打开应用播放、登录/注册或下载应用。按内容源状态选择分支，不把它们串成必经步骤。
- 同页还记录 Apps Row 获焦向上箭头改为非渐变、遮罩/设置颜色调整及骨架更新。实际应用前核对目标版本。

## 原型证据的解释

实际读取到 OOBE 的 ON_KEY_DOWN / KEYBOARD 事件（Enter、S、Space、Backspace 等）及约 0.3 秒的 Smart Animate / Ease Out。它们是桌面演示连线，不证明电视端遥控器键值或产品计时。部分 Layout 原型 action 的 destinationId 为 null，不能声称已经走通。

学习和交付时区分：图像说明了什么、文字规定了什么、有效原型连线支持什么、真机测试验证了什么。已有明确项目说明无需因缺少连线全部标为未知；没有任何依据的业务结果也不可由原型空连线补造。
